# Agent Workbench · 示例仓库

这是 CodeTrail 内置的阅读练习，代码仅用于展示，不会由阅读器执行。

## 从这里开始

1. 阅读 `choose_route`：为什么简单任务留在本地？
2. 查看 `stream_with_fallback` 的改动：为什么输出第一个 token 后不能直接重试？
3. 打开“工具调用”功能：入口校验与执行如何连接？
4. 选择一段代码，将它绑定到自己的功能。
5. 查看变更，再将确认后的功能标记为“已确认”。
6. 打开“相关逻辑”，分析 `choose_route`：查看 `stream_chat` 调用、`get_route_callback` 的函数值引用，以及 `Route` 定义。
7. 查看“对话入口”的“可能受影响”提示；它自身的已确认状态仍然保留。
8. 分析 `dispatch_plugin` 或 `stream_with_fallback`，观察动态目标为什么保持未解析。

## 示例变更

- 模型路由增加输入范围校验，阈值从 0.5 改为 0.65。
- 流式降级增加已输出标记，避免两次回答混在一起。
- 已绑定的测试只表示阅读证据，不表示测试通过或覆盖率。
