# 更新记录

## v0.2.0 — 相关逻辑与潜在影响

### 新增

- Python 一跳关系：调用方、被调用方、非调用引用以及动态/外部边界。
- 精确导入路径、导入别名与词法作用域的静态解析；无法确定的目标保留原因。
- 可点击的局部调用图和证据列表；调用位置与目标定义分别导航。
- 关系快照摘要与文件内容校验，阻止分析后源码变化导致的陈旧导航。
- 直接改动和依赖“可能受影响”分开呈现；不自动改变人工审阅状态。
- 可选 Pyright 语义增强，采用捕获源码的临时工作区、受限 Node 进程和有界请求。
- 历史版本关系边界：当前工作区关系不被当作历史影响结论。
- 演示增加对话入口、函数值回调和动态插件调用，以及两个相应功能。

### 保持兼容

- `.reader/` schema 仍为 1；原有 Feature、Anchor、阅读摘要无需手动迁移。
- 原有 Rust/Python/TS/JS 符号阅读、Git Diff、源码只读、标注和导出保持。
- 浏览器演示升级保留此前已保存的 v0.1 功能说明，并补充新的示例功能。
- 缺少可选语义服务时，静态分析和原有阅读流程仍可使用。

### 当前边界

- 关系解析先支持 Python，其他语言保留已有阅读能力。
- 关系是源码层面的绑定证据，不是动态执行轨迹或完整调用图。
- 只提示已解析的一跳依赖影响，不递归判断全仓库行为正确性。
- 没有新增 AI 自动解释、自动修改源码或自动文件监听。
- 本次仍以 Linux 进行原生验收；macOS 的运行和安装包需要在目标平台验收。

## v0.1.0 — 功能与代码的阅读工作台

实现本地只读源码、语法符号、人工 Feature、多片段绑定、双向导航、Git 对比和版本感知审阅。该版本完成 Linux 原生编译及真实 WebView/IPC 验收，作为 v0.2 的兼容回归基线。
